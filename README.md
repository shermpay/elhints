# elhints

Provide inline hints for Emacs Lisp buffers.

## Usage

elhints defines `elhints-mode` as a minor mode that provides hints.

```emacs-lisp
(require 'elhints)
(add-hook 'emacs-lisp-mode-hook 'elhints-mode)
```
